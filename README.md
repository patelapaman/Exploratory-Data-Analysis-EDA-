# Project 2: Exploratory Data Analysis (EDA) on Iris Dataset

## Internship
Codveda Technology – Data Analytics Internship

## Objective
Perform Exploratory Data Analysis on the provided Iris dataset to identify patterns, distributions, relationships, and summary statistics.

## Dataset Summary
- Rows: 150
- Columns: 5
- Numeric Features: sepal_length, sepal_width, petal_length, petal_width

## Analysis Performed
- Mean, median, mode, and standard deviation
- Missing-value analysis
- Duplicate-row analysis
- Histograms
- Boxplots
- Scatter plot
- Correlation heatmap

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn

## How to Run
```bash
pip install -r requirements.txt
python eda_iris.py
```
